# 💍 Engagement Invitation Website

A romantic and elegant engagement invitation website created as a personalized digital invitation for a special celebration.

The website provides guests with the event information, photo gallery, countdown, RSVP experience, and confirmation page in a simple and responsive design.

## 🌐 Live Website

[View the Live Website](https://caroljoy26.github.io/my-engagment-website/)

## ✨ Features

- 💍 Personalized engagement invitation
- 📅 Event information
- ⏳ Countdown to the celebration
- 📸 Photo gallery
- 📝 RSVP form
- ✅ RSVP confirmation page
- 📱 Responsive design for different screen sizes
- 🎨 Elegant and romantic visual design
- 🌐 Hosted using GitHub Pages

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages
